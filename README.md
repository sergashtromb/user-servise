# user-servise

# Требования

- Хранение пользователей (создание, редактирование, получение)
- Логирование событий изменений в бд а так же неудачных попыток (отдельная таблица бд)
- Кеширование сохранять получаемые данные в кеше Redis
- Для бд использовать PostgresSQL, черех pgx ограничивать количество одновременных запросов
- GRPs доступ
- реализация rate limiter (использовать готовые библиотеки)
- динамическое изменение настроек через http, а так же файл .yaml
